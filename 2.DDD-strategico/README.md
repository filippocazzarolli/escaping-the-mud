# DDD strategico — Trovare i confini

Dove finisce un modello e ne comincia un altro.

Il [percorso 1](../1.DDD-vs-framework/README.md) mette il dominio al centro. Qui si decide **quale**: un linguaggio che vale *dentro* un confine, non un modello unico grande quanto l'azienda.

## L'idea in una frase

Una parola vale solo **dentro** un contesto. Fuori, la stessa parola può mentire: si traduce al bordo, non si fonde il modello.
