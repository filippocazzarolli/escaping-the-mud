# Complessità e moduli profondi

Appunti di studio — non sostituiscono il libro.

Ispirati a [*A Philosophy of Software Design*](https://web.stanford.edu/~ouster/cgi-bin/book.php) (2nd ed.) di John Ousterhout. Qui restano solo le idee che si innestano su questo repo: uscire dal fango, dominio al centro, core protetto.

Per argomenti, esempi e ragionamenti completi: **leggi il libro**.
